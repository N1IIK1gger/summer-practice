## 3. Выводы

* **Квадратичные алгоритмы (Bubble, Selection, Insertion):** Демонстрируют экспоненциальный рост времени выполнения. Уже при размере массива $N=1000$ задержки становятся заметными на глаз, а при больших объёмах данных их использование становится практически неприемлемым.

* **Алгоритмы со сложностью $O(N \log N)$ (Merge, Quick, Heap):** Среди них `Quick Sort` показывает наилучшую производительность на случайных данных, обеспечивая минимальное время сортировки. `Heap Sort`, в свою очередь, выделяется экономным использованием оперативной памяти, так как требует всего $O(1)$ дополнительного пространства, что делает его оптимальным выбором при ограниченных ресурсах.

* **Встроенная сортировка Python (Built-in):** Ожидаемо оказывается самой эффективной благодаря реализации на низкоуровневом C и использованию продвинутого гибридного алгоритма Timsort, который адаптируется под структуру входных данных.

* **Сравнение интерпретаторов (PyPy vs CPython):** PyPy демонстрирует значительное преимущество в вычислительно-интенсивных задачах, ускоряя выполнение циклов в 3–10 раз. Этот прирост достигается за счёт JIT-компиляции, которая оптимизирует часто выполняемый код "на лету", в то время как классический CPython интерпретирует байт-код построчно без динамической оптимизации.



## 4. Ограничения и проблемы

* **Отсутствие замеров памяти для PyPy:** Модуль `tracemalloc` не поддерживается в PyPy из-за отсутствия реализации `_tracemalloc`, поэтому все значения в колонке `Memory_KB` для этого интерпретатора отмечены как `N/A`.

* **Пропуск тестов для $O(N^2)$ алгоритмов:** Пузырьковая сортировка, сортировка выбором и вставками не запускались на массивах размером $N=50\,000$ и $N=1\,000\,000$ во избежание критического роста времени выполнения, которое могло бы привести к многократному увеличению продолжительности эксперимента.

* **Проблемы с рекурсией у `Quick Sort`:** На уже отсортированных данных стандартная реализация быстрой сортировки может достичь максимальной глубины рекурсии, что приводит к возникновению ошибки `RecursionError`. Это связано с неудачным выбором опорного элемента, когда массив разбивается на несбалансированные части.
